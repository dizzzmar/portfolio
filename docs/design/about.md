# Design detail: About: layout and the holographic portrait

**Typography and colour direction (7 Nov 2026):** `visual-language.md` governs future changes. Existing layout descriptions below record the current implementation; the two-voice typography and flexible palette rules have not yet been applied in CSS.

Detail for this area of the design system. `DESIGN.md` holds the system and a summary; read this file only when working on this area, and keep new per-page detail here, not in `DESIGN.md`.

- **About (restored to the 28 Oct design, «foto grande y presentación a dos columnas»):** green page with lime text. On desktop the holographic portrait stays still on the left (sticky, up to 40 vw wide, 4:5, it still tilts to the mouse with a moving shadow) and the text card sits on the right (from 46 vw) and scrolls with the page: the huge «Mario Diz» title (Funnel Display), the biography in bold across both columns, two columns below (Art direction & visual design · Values), «Now playing» with the two covers, LinkedIn and the email under the two columns, Selected clients (the logos) and the FAQs link; then the big footer. The card enters from the right on a direct load (0.8 s) and each block fades up as it appears. On a phone the photo stays on top (sticky) and the card passes over it. The email shown is the current one (contact@dizmar.xyz, not the old Gmail one of that version) and the breadcrumbs and the small footer of that version are not back (the big footer replaces it). The images keep the mosaic load (js/pixel-load.js, `.px`; it measures the image through an ImageBitmap because with srcset + sizes `naturalWidth` is density-corrected and the crop came out magnified): each starts as an embedded 10-pixel-wide mosaic and sharpens in six steps when it arrives and is in view; `<html>` gets `fx` only when IntersectionObserver exists and reduced motion is not requested. The Locomotive-style version (4 Nov, PR #348) is in the history if it is ever wanted back.
- **The island scene is no longer on this page:** the portrait does not flip any more (it only tilts and shines, as before). The pixel-art island lives in the Playground at `/playground/island/`; its full description is in `docs/design/playground.md`.

- **Now playing / Last watched (About card):** two blocks side by side (stacked on a phone), each with its own bold heading, «Now playing» above the record and «Last watched» above the film, followed by a 60 % opacity «Updated Nov 6» typed by hand in `about/index.html` (`.np-date`); update the date whenever the record or the film changes.

- **FAQs (/faq/):** green page with lime text, two columns like Privacy: the title «FAQs» (sticky) with «Have any other question? Write to me →» under it on the left, and the questions on the right with **no horizontal lines and no numbers**: they are separated by space only. Each question is a large title in Funnel Display 600 (the system's Title, `clamp(24px, 2.8vw, 44px)`) with a round lime button (36–48 px, a green + inside) at the right; pressing it opens the answer below in body text, the + turns 45° into a × (and scales 1.12 on hover, 0.94 on press) and the other questions drop to 80 % opacity (5.1:1 on the green) until the pointer is over one. Only one is open at a time (`js/faq.js` closes the others; without JavaScript several can be open). It works without JavaScript and with the keyboard (Enter or Space on the question, focus ring in lime); **the open/close motion** (guide of emil-design-eng) is driven by `js/faq.js` with the Web Animations API, so it is the same in every browser: pressing a question grows its answer from 0 to its height in 0.32 s on the system's strong ease-out while it fades in and rises from −8 px (50 ms late, so it appears once there is room); the open one closes at the same time in 0.22 s and fades out in 0.12 s, so the list never jumps (one goes up as the other comes down); pressing in the middle of an animation continues from the exact height it had, never restarting from zero; only the answer's height, opacity and offset animate (the question row never moves, so the focus ring never clips); the button turns 135° in 0.3 s and the other questions ease between 100 % and 80 % opacity (all following `.is-open` / `.is-closing`, set at the press, not `[open]`, which is removed when the closing ends). With reduced motion the height does not animate (it opens at once with a 0.15 s fade). Without JavaScript the questions are plain `<details>` with the CSS height animation of Chrome and Edge. Add a question by copying a `<details class="faq-item" name="faq">` block in `faq/index.html` (the `--i` number only staggers the entrance). The `faq.css` version number goes up when the css changes.
